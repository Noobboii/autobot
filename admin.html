Sign in with a GitHub access key

This page changes your bot's settings directly on GitHub. Only someone holding an access key for your repo can see or change anything. The key stays in this browser and is never sent anywhere except GitHub.

  1. Create an access key. The permissions are filled in for you.
  2. Under Repository access, choose Only select repositories and pick your bot's repo.
  3. Click Generate token, copy it and paste it below.
