Privacy Policy

This is a personal automation tool. It publishes short videos to social media accounts owned by its operator, and it is not offered to the public.

What data it uses

The tool uses access tokens for the operator's own YouTube, Facebook, Instagram and X accounts. It uses them only to upload videos and captions to those accounts. It does not collect, store or process personal data from any other user.

Storage

Access tokens are stored as encrypted secrets in GitHub Actions. The tool keeps a public log of video titles, post dates and post links so the operator can monitor it.

Sharing

No data is sold or shared with third parties beyond the platform APIs needed to publish the videos.

Deletion

The operator can revoke access at any time from each platform's connected-apps settings. To request deletion of any data, open an issue on this tool's GitHub repository.
